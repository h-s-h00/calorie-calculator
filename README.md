# حاسبة السعرات الحرارية — دليل التركيب والنشر

موقع جاهز بالكامل (HTML + CSS + JS بدون أي إطار عمل)، مصمم كأداة محتوى تدرّ دخلاً عبر Google AdSense.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية: الحاسبة + المقال + الأسئلة الشائعة |
| `style.css` | كل التنسيقات |
| `script.js` | منطق الحساب والتحقق من المدخلات وأنيميشن النتائج |
| `privacy.html` | مسودة سياسة خصوصية (مطلوبة لقبول AdSense) |
| `ads.txt` | ملف تحقق مطلوب من AdSense بعد الحصول على حسابك |

## 1) قبل النشر: جهّز المحتوى

- افتح `privacy.html` وعبّئ البريد الإلكتروني والتاريخ بدل النصوص الموضوعة بين أقواس `[ ]`.
- غيّر اسم الموقع/الشعار النصي في `index.html` (البحث عن `حاسبة<em>السعرات</em>`) إذا أردت اسماً مختلفاً.
- إن كان لديك نطاق (دومين) خاص، استبدله في أي روابط مطلقة تضيفها لاحقاً.

## 2) النشر (استضافة مجانية سريعة)

أي استضافة ملفات ثابتة تعمل مباشرة بدون أي إعداد إضافي، مثال:

- **Cloudflare Pages** أو **Netlify**: اسحب مجلد الموقع وأفلته في لوحة التحكم، أو اربطه بمستودع GitHub.
- **GitHub Pages**: ارفع الملفات إلى مستودع، فعّل GitHub Pages من الإعدادات.
- استضافة مدفوعة عادية (cPanel وغيرها): ارفع الملفات عبر FTP إلى المجلد `public_html`.

في كل الحالات، تأكد أن `index.html` يبقى في المجلد الجذر (الرئيسي) للموقع.

## 3) التقديم على Google AdSense

1. اذهب إلى [google.com/adsense](https://www.google.com/adsense) وأنشئ حساباً بنطاقك.
2. **قبل التقديم**: تأكد من وجود محتوى كافٍ وأصلي (المقال + الأسئلة الشائعة موجودان في الصفحة)، وأن `privacy.html` مكتملة، وأن الموقع يعمل عبر **HTTPS**.
3. بعد الموافقة، سيعطيك AdSense سكربتاً يشبه هذا:

   ```html
   <script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXXXXXXXXXXXXXX" crossorigin="anonymous"></script>
   ```

   الصقه داخل `<head>` في `index.html` و`privacy.html` (يوجد مكان محجوز له في تعليق داخل `<head>` بملف `index.html`).

4. حدّث ملف `ads.txt` برقم الناشر (`pub-XXXXXXXXXXXXXXXX`) الحقيقي الخاص بك، وارفعه في جذر الموقع.

## 4) وضع كود الإعلانات في أماكنه

الموقع فيه **5 أماكن جاهزة ومعلّمة** بالتعليق التالي في `index.html`:

```html
<div class="ad-slot ad-slot--leaderboard" aria-hidden="true">
  <span class="ad-slot__tag">مساحة إعلانية</span>
  <!-- الصق هنا كود <ins class="adsbygoogle">...</ins> -->
</div>
```

الأماكن الخمسة:
1. أعلى الصفحة (لافتة عريضة)
2. بعد نتيجة الحاسبة مباشرة (مستطيل)
3. داخل المقال (منتصف المحتوى)
4. الشريط الجانبي (يظهر فقط على الشاشات الكبيرة)
5. قبل التذييل (لافتة عريضة)

لكل مكان، اذهب في لوحة تحكم AdSense إلى **"إعلانات" → "حسب الوحدة الإعلانية" → إنشاء وحدة جديدة**، انسخ الكود الذي يعطيك إياه (يبدأ بـ `<ins class="adsbygoogle" ...>`)، والصقه مكان التعليق `<!-- الصق هنا ... -->` داخل كل `div.ad-slot`.

**نصيحة:** لا تضع كل الأماكن الخمسة دفعة واحدة إن كنت في بداية الموقع — ابدأ بمكانين أو ثلاثة، وراقب الأداء وتجربة المستخدم قبل زيادة عدد الإعلانات، فهذا يحسّن كلاً من تجربة الزائر وموافقة AdSense على المدى الطويل.

## 5) بعد التفعيل

- تأكد من ظهور الإعلانات فعلياً بعد 24–48 ساعة من تركيب الكود (تحتاج Google وقتاً للزحف والموافقة على كل صفحة).
- راقب معدل الارتداد وسرعة تحميل الصفحة — إعلانات كثيرة أو بطء التحميل يقلل الزيارات والدخل معاً.
- استمر بإضافة محتوى ومقالات صحية مرتبطة (مثال: حاسبة الماء، حاسبة كتلة الجسم) لزيادة الزيارات العضوية من محركات البحث، فهي المصدر الحقيقي للدخل السلبي على المدى الطويل، وليس عدد الإعلانات نفسه.
