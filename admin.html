First-Time Setup (once only)

To manage your site with one click, without going back to GitHub, you need to link the dashboard to a personal access key for your account. It's used only from your browser, and is never sent anywhere except GitHub.

  1. 1 Click the button below — it takes you to the GitHub key creation page
  2. 2 In the Token name field, type any name, e.g.: Dashboard
  3. 3 In Repository access, choose: Only select repositories → then select calorie-calculator
  4. 4 Scroll to Permissions → Repository permissions → find "Contents" → set it to Read and write
  5. 5 Scroll down and click Generate token
  6. 6 Copy the key that starts with github_pat_... (shown only once)
  7. 7 Come back here and paste it in the field below
Open the key creation page →

Saved only in your own browser — never sent to us or any third party.
