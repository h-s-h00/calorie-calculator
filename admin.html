الإعداد الأول (مرة وحدة فقط)

عشان تنشر بضغطة زر بدون الرجوع لـ GitHub، محتاج تربط الصفحة بمفتاح دخول خاص بحسابك. يستخدم فقط من متصفحك، ولا يُرسل لأي جهة غير GitHub.

  1. ١ اضغط الزر بالأسفل، بيوديك لصفحة إنشاء مفتاح بـ GitHub
  2. ٢ بخانة Token name اكتب اسم أي شي، مثلاً: نشر المقالات
  3. ٣ بخانة Repository access اختر: Only select repositories ← ثم اختر calorie-calculator
  4. ٤ انزل لـ Permissions ← Repository permissions ← دوّر "Contents" ← غيّرها لـ Read and write
  5. ٥ انزل تحت واضغط Generate token
  6. ٦ انسخ المفتاح اللي يبدأ بـ github_pat_... (يظهر مرة وحدة بس)
  7. ٧ ارجع هنا والصقه بالخانة تحت
فتح صفحة إنشاء المفتاح ←
